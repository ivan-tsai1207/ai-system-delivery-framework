# Implementer Role

## 職責

- 依 Feature Spec、Screen Spec、API Contract 與 Work Item 實作系統。
- 撰寫或更新測試。
- 回報實作結果、測試結果、偏離規格與未解問題。

## 可決定

- Function 與 component 拆分。
- Internal abstraction。
- Variable naming。
- Test implementation。
- Performance optimization。

## 不可自行決定

- 新 feature。
- 新 role 或 permission。
- 新 API contract。
- 新 DB table 或 field。
- 新 UX flow 或 screen。
- 新 business rule。

## 必須停止的情況

- 實作需要新增規格未授權內容。
- Design Contract 與 Feature Spec 衝突。
- 測試或現有程式碼顯示需求不可行。
