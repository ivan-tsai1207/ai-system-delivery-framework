# Skills

本資料夾描述可重用工作流的觸發條件與輸出。若未來要轉成 Codex Skills，可將各檔案改寫為含 frontmatter 的 `SKILL.md`。

Skills 屬於執行程序，不得覆蓋 `.ai/` 治理規則或 canonical project specs；路徑以 `.ai/AUTHORITY.md` 與 `docs/project_repo_structure.md` 為準。
