## 使用規則

- Raw design source 不等於 Source of Truth。
- Raw design source 必須轉成 Screen Spec / UX Contract 後，才可交給 Codex 實作。
- 若來源內容與 PRD、Architecture、Feature Spec 或權限規則衝突，需標記為 Rejected 或提出 Change Request。
- HTML prototype 可作為 visual reference 或 implementation reference，但不得自行引入未授權需求。
