## Lifecycle Rule

```text
Proposed
→ Under Review
→ Approved
→ Canonical Spec Updated
→ Implemented
→ Closed
```

- Change Request 本身不是永久 Source of Truth。
- Approved CR 必須先寫回受影響的 canonical PRD、SRS、Architecture、SDD 或 Feature Spec。
- 在狀態成為 `Canonical Spec Updated` 前，下游 Agent 不得依 CR 改變設計或實作。
